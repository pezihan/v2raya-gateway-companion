# v2rayA 旁路网关智能分流助手 (v2rayA Gateway Companion)

针对将 Linux 作为局域网透明网关（TPROXY）并在 v2rayA 中使用 RoutingA 模式的用户量身打造的现代化智能管理面板与测墙探针。

---

## ✨ 核心特性

1. **🎯 局域网定向 IP 流量嗅探与测墙计划**：
   - 输入或下拉选择局域网内任意客户端 IP（如你的手机 `192.168.1.50`）。
   - **底层双通道嗅探**：同时捕获该 IP 发起的 DNS 解析（UDP 53）与 HTTPS TLS 握手 SNI（TCP 443）。即使手机开启了 DoH 加密 DNS，也能 100% 捕获外网域名。
   - **智能自动过滤**：已命中当前 RoutingA 代理规则或已成功翻墙的常规请求**自动忽略**，不产生任何干扰。
   - **主动测墙研判**：对走直连的请求，实时通过“国内/海外 DNS 投毒对比”与“直连 TCP RST 探测”进行验证，确认被阻断才推送到前端。

2. **💡 一级根域名智能识别与覆盖推荐**：
   - 嗅探到具体子域（如 `api-us.tiktokv.com` 或 `www.google.com`）时，自动推导一级根域名（`tiktokv.com`、`google.com`）。
   - 提供 **【+ 保存根域名到代理】**（一键覆盖该域名下所有二级、三级子域名）或 **【+ 仅该子域名】** 双重选择。

3. **⚡ 任意长网址直接粘贴清洗**：
   - 支持直接从浏览器地址栏复制完整网址（例如 `https://www.pornhub.com/view_video.php?viewkey=...`）。
   - 自动剔除 `https://`、端口、路径与参数，实时显示提炼后的纯净域名，并可一键切换至根域名。

4. **📋 RoutingA 规则可视化看板与语法去重**：
   - 告别单调易错的纯文本框，将规则转化为精美卡片分类展示（`Telegram`、`自定义代理`、`强制直连` 等）。
   - **🧹 一键语法去重排错**：自动清理多余的 `full:` 规则以及已包含在根域名下的重复子域名（例如已有 `domain:telegram.org` 时自动清理冗余的 `full:telegram.org` 和 `domain:web.telegram.org`）。
   - 支持一键切换纯文本编辑。

5. **🎨 高颜值暗黑玻璃拟态 UI**：
   - 基于 Tailwind CSS 与 Vue 3 构建的高级暗黑色调界面，支持 WebSocket 实时秒级推流与雷达动态指示灯。

## 🚀 快速开始与部署（Docker 推荐）

### 方式一：Docker Compose 一键启动（推荐）

1. 将本项目目录复制到你的 Linux 网关机器上：
   ```bash
   cd v2raya-gateway-companion
   ```

2. 检查 `docker-compose.yml`：
   > **注意**：容器采用 `network_mode: "host"`，这是抓取网关底层局域网数据包并直接与宿主机 `127.0.0.1:2017` 的 v2rayA 通信的必需配置。同时挂载了宿主机的 `/etc/v2raya` 目录用于读取和同步规则。

3. 启动容器：
   ```bash
   docker compose up -d --build
   ```

4. 打开浏览器访问：
   - **本助手管理面板**：`http://<你的Linux_IP>:2018`
   - **v2rayA 原生面板**：`http://<你的Linux_IP>:2017`

---

### 方式二：一键脚本启动

执行自带的启动脚本，脚本会自动识别环境并启动：
```bash
./run.sh
```

## 📱 使用流程演示

### 场景 1：手机刷某个应用打不开，排查并加入分流
1. 打开 `http://<Linux_IP>:2018`，进入 **【🎯 定向嗅探】** 标签页。
2. 在设备选择框中选择你的手机 IP（或手动输入如 `192.168.1.50`）。
3. 点击 **【启动监测计划】**。
4. 拿起手机，打开那个原本打不开或加载缓慢的 App/网页。
5. 面板上将实时弹出一连串被墙的域名卡片，并醒目标注阻断原因（如 `[TCP RST 重置]`、`[DNS 投毒]`）。
6. 直接点击卡片上的 **【+ 保存根域名到代理】**。
7. 规则自动追加到 RoutingA 并重载 v2rayA，手机立刻无需重连 Wi-Fi 即可顺畅访问！

### 场景 2：电脑浏览器随手粘贴长 URL
1. 进入 **【⚡ 智能添加】** 标签页。
2. 将打不开的网址完整粘贴到输入框中。
3. 系统瞬间提取出纯净 Hostname，如果带有 `www.` 等子域，会自动弹出“采用一级根域名”提示。
4. 点击 **【检测是否被墙】**，查看直连与解析状态。
5. 点击 **【+ 添加并同步到 v2rayA】** 即可。

## ⚙️ 环境变量配置说明

| 变量名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `PORT` | `2018` | 本服务 WebUI 访问端口 |
| `V2RAYA_URL` | `http://127.0.0.1:2017` | 宿主机 v2rayA Web 界面地址 |
| `V2RAYA_DB_PATH` | `/etc/v2raya/v2raya.db` | v2rayA 规则 SQLite 数据库路径 |
| `DOMESTIC_DNS` | `223.5.5.5` | 用于对比检测 DNS 污染的国内上游 DNS |
| `OVERSEAS_DOH` | `https://1.1.1.1/dns-query` | 用于对比真实解析的海外安全 DoH 接口 |
